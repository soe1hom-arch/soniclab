# Screenshots

Save screenshots in this folder using the names below, then enable the table
in the "Screenshots" section of [`README.md`](../README.md):

| File | Content |
|---|---|
| `player.png` | Player screen (including track format info) |
| `equalizer.png` | Equalizer screen (vertical 10-band EQ) |
| `settings.png` | Settings screen (including the Output Audio section) |
| `studio.png` | Studio screen (tool result) |

Recommended: captures from a real device, dark theme, 1080×2400 or the
device's native resolution.
