# Tangkapan Layar (Screenshots)

Simpan tangkapan layar di folder ini dengan nama berikut, lalu hapus komentar
tabel di bagian "Tangkapan Layar" pada `README.md`:

| Berkas | Isi |
|---|---|
| `player.png` | Layar Player (termasuk info format lagu) |
| `equalizer.png` | Layar Equalizer (EQ 10-band vertikal) |
| `settings.png` | Layar Pengaturan (termasuk section Output Audio) |
| `studio.png` | Layar Studio (hasil tool) |

Rekomendasi: tangkapan layar dari perangkat nyata, mode gelap, 1080×2400
atau ukuran asli perangkat.
